# Utility Scripts

This directory contains various utility scripts used for Jaeger development, CI/CD, and documentation generation.

## Metrics Utilities

### generate_metrics_docs.py

Converts Prometheus metrics to documentation-friendly markdown format. This script is used to generate metrics documentation that can be incorporated into the Jaeger documentation website.

**Usage:**

```bash
# Generate docs from a metrics file
python3 generate_metrics_docs.py --input metrics.txt --output metrics.md

# Generate docs from a URL (e.g., running Jaeger instance)
python3 generate_metrics_docs.py --url http://localhost:8888/metrics --output metrics.md

# Include instance-specific labels in the documentation
python3 generate_metrics_docs.py --input metrics.txt --include-instance-labels

# Custom title and description
python3 generate_metrics_docs.py --input metrics.txt --title "My Metrics" --description "Custom description"
```

**Via Makefile:**

```bash
make generate-metrics-docs INPUT=/path/to/metrics.txt OUTPUT=/path/to/output.md
```

**Output Format:**

The generated markdown includes:
- Overview and table of contents
- Metrics grouped by category (Jaeger Core, OpenTelemetry Collector, Receiver, etc.)
- Summary tables with metric name, type, labels, and description
- Detailed sections for each metric with full label information

### compare_metrics.py

Compares two Prometheus metric files and generates a unified diff. Used in CI to detect breaking changes in metrics.

**Usage:**

```bash
python3 compare_metrics.py --file1 metrics_v1.txt --file2 metrics_v2.txt --output diff.txt
```

### metrics-md.py

Generates markdown tables comparing V1 and V2 Jaeger metrics. Used for migration documentation.

**Usage:**

```bash
python3 metrics-md.py
```

**Note:** This script requires paths to be configured within the script before use.

## Integration with Documentation Website

The metrics documentation generated by `generate_metrics_docs.py` can be incorporated into the Jaeger documentation website (jaegertracing.io) in several ways:

### 1. During Release Process

Metrics snapshots from the latest release can be converted to markdown and included in the documentation:

```bash
# Download metrics artifact from release
# Generate documentation
make generate-metrics-docs INPUT=metrics_snapshot.txt OUTPUT=docs/metrics.md
```

### 2. From CI Artifacts

The CI workflow already uploads metrics snapshots as artifacts. These can be processed:

1. Download the metrics artifact from GitHub Actions
2. Run `generate_metrics_docs.py` on the snapshot
3. Include the generated markdown in the documentation

### 3. Live Documentation

For development or preview purposes, generate documentation from a running Jaeger instance:

```bash
# Start Jaeger
go run ./cmd/jaeger --config ./cmd/jaeger/config.yaml &

# Wait for startup and generate docs
sleep 5
python3 scripts/utils/generate_metrics_docs.py \
  --url http://localhost:8888/metrics \
  --output metrics-reference.md
```

## Testing

Unit tests are available for the metrics documentation generator:

```bash
cd scripts/utils
python3 -m pytest generate_metrics_docs_test.py -v
```

## Categories

The script organizes metrics into the following categories:

- **Jaeger Core Metrics**: Metrics starting with `jaeger_`
- **OpenTelemetry Collector Metrics**: Metrics starting with `otelcol_`
- **Receiver Metrics**: Metrics starting with `receiver_`
- **Exporter Metrics**: Metrics starting with `exporter_`
- **Processor Metrics**: Metrics starting with `processor_` or `batch_`
- **RPC Metrics**: Metrics starting with `rpc_`
- **HTTP Metrics**: Metrics starting with `http_`
- **Process Metrics**: Metrics starting with `process_`
- **Go Runtime Metrics**: Metrics starting with `go_`
